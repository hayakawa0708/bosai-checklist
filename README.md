# bosai-checklist（防災持ち出し袋チェックリスト）

防災持ち出し袋の中身を点検するためのチェックリスト。持ち出し袋にQRコードを貼っておき、スマホで読み取って開く。インストール不要・外部通信ゼロの単一HTMLアプリ。

## 必要なもの

- ブラウザだけで動きます（Python・APIキー・インストール不要）

## 起動方法（PCで内容を編集したいとき）

- Windows: `01_アプリ起動.bat` をダブルクリック
- Mac: 初回のみターミナルで `chmod +x *.command` を実行 → 以後 `01_アプリ起動.command` をダブルクリック

実際の運用ではGitHub Pagesで公開したURLをQRコードにして、スマホから直接開く（下記「QRコードでスマホから使う」参照）。

## 使い方

1. 持ち物を確認したらチェックを入れる
2. 新しい持ち物はフォームから追加（名前は必須、個数・消費期限は任意）。項目名・個数・消費期限は一覧の中で直接編集できる
3. 消費期限が今日より前の項目は「期限切れ」で赤、30日以内は「期限間近」で黄色に表示される
4. 点検が一通り終わったら「点検完了」を押す。最終点検日時が記録され、チェックは全部リセットされる（次回点検時に前回のチェックが残って誤認しないようにするため）
5. 定期的に「JSONで書き出す」でバックアップを取る（機種変更・ブラウザのデータ削除で内容が消えるため。書き出したファイルはこのフォルダの外、例えばOneDrive等に保管する）

## QRコードでスマホから使う（GitHub Pages）

1. `02_GitHubへアップロード.bat`（Macは `.command`）を実行し、`bosai-checklist` という**空のリポジトリ（Public）**をGitHub上に作成してpushする
2. GitHubリポジトリの `Settings → Pages` で、Branch: `main` / フォルダ: `/ (root)` を選択して保存する
3. 数分後に `https://<GitHubユーザー名>.github.io/bosai-checklist/` が公開される。このURLをQRコードに変換し、印刷・ラミネートして持ち出し袋に貼る
4. 以後はQRコードを読み取るだけで最新版が開く。中身リストをPC側で更新してpushし直すと、次回スマホで開いたときに初期リストも更新される（すでにスマホ側で追加・編集した項目はそのまま残る）

## 保存されるデータ（PC移行時に注意）

- 持ち物リスト・チェック状態・最終点検日時は、ブラウザの`localStorage`に保存される
- **その端末・そのブラウザだけに保存され、他の端末とは同期しない**。ブラウザのデータ削除や機種変更で消える
- このデータは`.gitignore`の対象でもなく最初からGitリポジトリに含まれない（ブラウザ内にしか存在しない）ため、`git clone`では引き継げない。定期的な「JSONで書き出す」バックアップが唯一の保存手段

## 公開設定について

- このリポジトリは**意図的にPublic**にする（droneプロジェクトと同様の判断）。GitHub Pagesの無料利用にはPublicリポジトリが必要で、持ち出し袋の中身一覧が外部に見えても問題ない前提
- GitHubにコミットされるのは「初期の持ち物リストとアプリ本体（index.html）」だけで、スマホ側でlocalStorageに追加・編集した内容は自動的には公開されない
- ただし、「JSONで書き出す」で作ったバックアップファイルや、薬の名前・連絡先など個人情報を書き込んだメモを、誤ってこのリポジトリへコミットしないこと

## バックアップ（GitHub）

- 保存: `02_GitHubへアップロード.bat`
- 最新版の取得（PC側での編集用）: `03_GitHubからダウンロード.bat`

## トラブルシューティング

- **保存したはずのデータが消えた** → ブラウザの「サイトデータを削除」をした、別のブラウザ・別の端末で開いた、のいずれかが主な原因。JSONバックアップから「JSONから復元する」で復元する
- **「保存データを読み込めませんでした」という警告が出た** → 保存データが壊れている可能性がある。バックアップがあれば「JSONから復元する」で読み込む。無い場合は警告内の「新規作成を続ける」を押すと空の状態から使えるが、元の保存データ自体は上書きしない（押すまでは消えていない）
- **iPhoneのSafariで「JSONで書き出す」を押すとファイルが別タブで開く** → 共有ボタンから「ファイルに保存」を選ぶ
